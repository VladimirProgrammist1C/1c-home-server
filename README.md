## 🚀 Быстрый старт <a name="-быстрый-старт"></a>

### Предварительные требования <a name="предварительные-требования"></a>
- ✅ Windows 11 Pro x64
- ✅ Docker Desktop + WSL2
- ✅ Git
- ✅ Tailscale (для защищённого доступа)

### Установка за 5 минут <a name="установка-за-5-минут"></a>

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/VladimirProgrammist1C/1c-infrastructure.git
cd 1C_Infrastructure

# 2. Настроить пароли
Copy-Item .env.example .env
notepad .env  # ← изменить пароли и пути!

# 3. Запустить инфраструктуру
docker-compose up -d

# 4. Проверить статус
docker-compose ps  # все сервисы должны быть "Up (healthy)"
```

## 🌐 Доступ к сервисам <a name="-доступ-к-сервисам"></a>

**Локально:** `localhost` или `127.0.0.1`  
**Удалённо (безопасно):** `100.x.x.x` через **Tailscale VPN**

> 🔐 **Tailscale** обеспечивает **безопасный защищённый доступ** через зашифрованный туннель (WireGuard). Проброс портов не требуется.  
> 🖥️ **RDP** используется непосредственно для удалённого подключения, но весь трафик идёт через защищённый туннель Tailscale.

### Алерты (12 правил) <a name="алерты-12-правил"></a>

#### 🏗️ Инфраструктура (9 правил) <a name="️-инфраструктура-9-правил"></a>
| Алерт | Критичность | Условие |
|-------|-------------|---------|
|  PostgreSQL is DOWN | Critical | `pg_up == 0` |
| 🔴 Portainer Down | Critical | HTTP проверка не прошла |
| 🔴 pgAdmin Down | Critical | HTTP проверка не прошла |
|  Grafana is DOWN | Critical | HTTP проверка не прошла |
| 🔴 Prometheus is DOWN | Critical | `up{job="prometheus"} == 0` |
| 🔴 VoceChat-Notify is DOWN | Critical | HTTP проверка не прошла |
| 🔴 cAdvisor is DOWN | Critical | `up{job="cadvisor"} == 0` |
| 🟡 High CPU Usage | Warning | `> 80%` (5 min avg) |
| 🟡 High Memory Usage | Warning | `> 1 GB` |

#### 📊 Бизнес-метрики 1С (3 правила) <a name="-бизнес-метрики-1с-3-правила"></a>
| Алерт | Критичность | Условие |
|-------|-------------|---------|
| 🟡 High Database Size | Warning | База > 5 ГБ |
| 🟡 High 1C Connections | Warning | Всего подключений > 10 |
|  High User Connections | Warning | Подключений юзера > 2 |

##  Скрипты и автоматизация <a name="-скрипты-и-автоматизация"></a>

### Интерактивный бэкап <a name="интерактивный-бэкап"></a>

Добавлен интерактивный скрипт полного бэкапа инфраструктуры с 4 этапами.

📁 **Папка:** [`scripts/backup-scripts/`](scripts/backup-scripts/)

**Возможности:**
- ✅ **4-этапный бэкап** с интерактивным выбором:
  - Конфиги проекта (docker-compose.yml, .env, monitoring/)
  - Не-1С базы PostgreSQL (через whitelist)
  - Конфиги PostgreSQL (postgresql.conf, pg_hba.conf)
  - Docker volumes и bind mounts
- ✅ **Whitelist не-1С баз** — защита от случайного бэкапа рабочих 1С баз
- ✅ **Start-Process** вместо `docker run` — без зависаний терминала
- ✅ **Проверка целостности** gzip-архивов
- ✅ **Прогресс-бар** и логирование в `backup.log`
- ✅ **Маркеры** `[W]` (whitelist), `[B]` (bind mount), `[SKIP]` (пропущено)
- ✅ **Интерактивные команды:** `1-4`, `a`, `s`, `q`

**Запуск:**
```powershell
cd E:\1C_Infrastructure\scripts\backup-scripts
.\full-backup-rus.ps1
```

## 🛠️ Диагностика <a name="️-диагностика"></a>

### Сервис не запускается? <a name="сервис-не-запускается"></a>
```powershell
# 1. Проверить логи
docker-compose logs <service_name> --tail 100
# 2. Проверить статус
docker-compose ps
# 3. Пересоздать контейнер
docker-compose up -d --force-recreate <service_name>
```

### Алерты не срабатывают? <a name="алерты-не-срабатывают"></a>
```powershell
# 1. Проверить targets в Prometheus
# → http://localhost:9090/targets
# 2. Перезапустить Prometheus
docker-compose restart prometheus
```
