## 📋 Описание

Демонстрация PowerShell-скрипта резервного копирования Docker-инфраструктуры (тестовый режим).

В видео показана работа интерактивного PowerShell-скрипта для резервного копирования домашней Docker-инфраструктуры с 1С, PostgreSQL и пользовательскими сервисами.

---

## 🔧 Два режима работы

Скрипт поддерживает два режима работы:

### 🧪 Тестовый режим (`-Test`)

Выполняет полный прогон сценария **без фактического копирования данных**, позволяя безопасно проверить настройки и оценить объём резервной копии.

**Преимущества:**
- ✅ Безопасная проверка конфигурации
- ✅ Оценка размера будущего бэкапа
- ✅ Понимание процесса без риска
- ✅ Быстрое выполнение (~3 минуты)

### ⚡ Боевой режим

Выполняет реальное создание резервных копий всех выбранных компонентов.

---

## ✨ Основные возможности

- ✅ Резервное копирование Docker-проекта и конфигурационных файлов
- ✅ Создание дампов PostgreSQL для выбранных сервисов Docker
- ✅ Сохранение конфигурации PostgreSQL
- ✅ Резервное копирование Docker Volumes и Bind Mounts
- ✅ Пошаговое интерактивное управление
- ✅ Выбор отдельных этапов или полный запуск
- ✅ Журналирование и итоговый отчёт
- ✅ **Безопасная проверка сценария перед продуктивным запуском**

---

##  Что показано в видео

1. **Запуск скрипта с флагом `-Test`**
   ```powershell
   & ".\full-backup-rus.ps1" -Test
   ```

2. **Интерактивное меню выбора этапов:**
   - Этап 1: Конфиги проекта (docker-compose.yml, .env, monitoring/)
   - Этап 2: Не-1С базы PostgreSQL
   - Этап 3: Конфиги PostgreSQL
   - Этап 4: Volumes и Bind Mounts

3. **Проверка whitelist баз данных:**
   - postgres
   - gitea
   - vocechat_notify
   - analytics
   - grafana
   - prometheus
   - portainer

4. **Тестовый прогон без сохранения:**
   - Показывает, что будет скопировано
   - Отображает размеры данных
   - Выводит ожидаемый результат

5. **Итоговая статистика:**
   - Общий размер бэкапа: ~1.64 ГБ
   - Количество файлов: 11698
   - Пропущенные этапы

## 💡 Зачем нужен тестовый режим?

Данный тестовый прогон демонстрирует:

- ✅ **Удобство управления** — интерактивное меню с выбором этапов
- ✅ **Прозрачность работы** — видно каждый шаг до фактического выполнения
- ✅ **Отказоустойчивый подход** к резервному копированию
- ✅ **Безопасную проверку** всех этапов перед выполнением реального бэкапа
