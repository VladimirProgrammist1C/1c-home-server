## 📋 Описание

Демонстрация PowerShell-скрипта резервного копирования Docker-инфраструктуры (боевой режим).

В видео показан реальный запуск интерактивного PowerShell-скрипта резервного копирования домашней Docker-инфраструктуры с сервисами 1С и PostgreSQL.

### 🔐 Двухуровневая схема резервного копирования

Для обеспечения отказоустойчивости используется двухуровневая схема резервного копирования:

- **Информационные базы 1С** архивируются отдельно при помощи Обновлятора 1С Владимира Милькина
- **PowerShell-скрипт** выполняет резервное копирование инфраструктурной части: Docker-проектов, PostgreSQL-баз сервисов, конфигурации PostgreSQL, Docker Volumes и Bind Mounts

Такой подход позволяет независимо восстанавливать как данные 1С, так и серверную инфраструктуру.

## ✨ Основные возможности

- ✅ Резервное копирование Docker-проектов и конфигурационных файлов
- ✅ Создание дампов PostgreSQL для сервисов

- ✅ Архивация Docker Volumes и Bind Mounts

- ✅ Журналирование и итоговая статистика
- ✅ Контроль размеров резервных копий

## 📊 Результаты бэкапа

В результате формируется полный комплект резервных копий, включающий:

- 📦 Архивы информационных баз 1С (через Обновлятор 1С)
- 📦 Дампы PostgreSQL сервисов (postgres, gitea)
- 📦 Конфигурацию PostgreSQL (postgresql.conf, pg_hba.conf, pg_ident.conf)
- 📦 Docker Volumes (9 томов: PostgreSQL, pgAdmin, Grafana, Prometheus, Portainer, Gitea, VoceChat-Notify, Аналитика, VoceChat)
- 📦 Bind Mounts (VoceChat семейный)
- 📦 Конфигурационные файлы проектов (docker-compose.yml, .env, monitoring/)
